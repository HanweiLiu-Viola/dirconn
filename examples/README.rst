Tutorials
=========

Fourteen tutorials, each a short script that runs from top to bottom and ends on what its result does
and does not show. Tutorials 1 to 6 and 9 to 12 use simulated data only (tutorial 11 needs the ``pcmci`` extra). Tutorials 7, 8, 13 and 14 need the MNE
``sample`` dataset (about 1.5 GB), which dirconn never downloads without being asked.
