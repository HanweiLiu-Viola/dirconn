Tutorials
=========

Seventeen tutorials, each a short script that runs from top to bottom and ends on what its result
does and does not show. Tutorials 1 to 6, 9 to 12 and 15 to 17 use simulated data only (tutorial 11
needs the ``pcmci`` extra, tutorial 17 the ``app`` extra). Tutorials 7, 8, 13 and 14 need the MNE
``sample`` dataset (about 1.5 GB), which dirconn never downloads without being asked. Tutorials 1 to
16 call the library from Python; tutorial 17 runs the ``dirconn-bids`` command line on a BIDS
dataset.
